🎯Thigh gap 誠實指南

你嘅觀察係啱嘅：負重練內側大腿（adductor）會愈練愈粗。gap 由三樣嘢決定：
  • 骨盆結構 — 改唔到，唔使同自己過唔去
  • 整體體脂 — 體脂去到 19-20%，內側自然收（成個 plan 本身就係）
  • 內側肌肉量 — 避開會「大」嘅動作
❌ 見到呢啲動作嘅「thigh gap workout」即刻 skip
  • 負重 Sumo squat（闊腳深蹲）— adductor 主導，練大內側
  • Adductor 機／夾腿機
  • Ankle weights 側臥內側抬腿（夾重量嗰種）
  • 好多片標「slim thighs」但開場就 sumo squat — 你已經中過招
✅ 應該做：練臀大肌＋臀中肌（視覺開 gap 位）
  • Hip thrust／Glute bridge — 臀大肌主力，plan 已包
  • RDL — 膕繩肌＋臀下層
  • 窄距 squat／Reverse lunge／Step-up — 唔會撐大內側
  • 臀中肌耐力（輕量高下數）：Side-lying leg raise 無負重 2×25、Clamshell 2×25、mini band Monster walk
  • 無負重慢速 Pilates 式內側動作一週 1-2 次可以

📲Apple Health／Fitness 自動同步

eify 冇公開 API，直接接唔到 — 兩條現實路：①eify app 內搵「同步至 Apple Health」開咗，之後呢個捷徑自動拉體重/體脂 ②量完喺 📏 量度 tab 手動填（30 秒）。⭐Apple Health 嘅水分%（water%）好多 scale app 唔 sync — 呢格照手動填。⭐你 Health 單位係 kg：捷徑 JSON 加 unit:"kg"，server 自動轉 lbs。
Shortcut step-by-step (FULL ENGLISH — follow exactly)
⭐ 關鍵：Find Health Samples 甩出嚟係 sample 物件，必須加 Get Details of Health Sample → Value 先係數字；步數要用 Calculate Statistics → Sum。唔使填日期（server 自動用香港今日）。
  1. First make sure your scale app syncs to Apple Health (in the scale app: Settings → Apple Health → enable Body Mass / Body Fat Percentage)
  2. Shortcuts app → + (New Shortcut) → tap the name → rename it Health to Diary
  3. Add action Find Health Samples → tap the highlighted Type → search and choose Body Mass → expand the action → set Limit = 1 and Sort By = Date, Newest First
  4. Add action Get Details of Health Sample → its input auto-fills with the Body Mass sample → set Detail = Value ← 呢步先係真數字
  5. Add action Find Health Samples → Type = Body Fat Percentage → Limit 1, newest first
  6. Add action Get Details of Health Sample → Detail = Value
  7. Add action Find Health Samples → Type = Steps → tap Add Filter → Start Date Is Today
  8. Add action Calculate Statistics → Statistics = Sum（input 自動接住 Steps samples）← 今日總步數
  9. Add action Find Health Samples → Type = Apple Exercise Time → Add Filter → Start Date Is Today
  10. Add action Calculate Statistics → Sum ← 今日運動分鐘
  11. Add action Get Contents of URL → URL: https://health-diary-sync.leunghlk.workers.dev/api/health
  12. Expand it → Method: change GET to POST
  13. Expand → Headers: add field — Key: X-Diary-Key, Value: 1ea6694cef20345a6d18bc7ce550cab0
  14. Expand → Request Body: choose JSON → tap Add New Field ×5（key 逐個打字，value 㩒住揀上面嘅變數）：weight＝Body Mass 嗰個 Value；bf＝Body Fat 嗰個 Value；steps＝第一個 Sum；exercise_min＝第二個 Sum；unit＝打字 kg（⭐你 Health 係 kg — server 自動轉 lbs，已實測 53.2kg→117.3lbs；如果第日轉用 lbs 就填 lbs）。❌ 唔好加 d／date field
  15. Add action Show Result → input auto = Contents of URL result（行完會見 server 回覆）
  16. Tap ▶ Run — 第一次行會問 Health permission → Allow All。預期結果：{"ok":true,...} 入面見到你嘅體重／步數
Debug： ① 想試連線 → Safari 開 https://health-diary-sync.leunghlk.workers.dev/api/ping，見 {"ok":true,...} 即網絡通（呢條唔使 key）； ② Run 時死喺 Find Health Samples ＝ Health permission 未批（再行一次揀 Allow）； ③ 回覆有 ok:true 但頁面冇數 ＝ header key 打錯（對第 13 步）； ④ Automation：Automations → New → Time of Day 21:00 → Run this shortcut。
